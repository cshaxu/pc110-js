# M2 T3 S6 P2 PCjs Change Report: 8042 Controller Core

## Summary

- Affected PCjs-derived subsystem: selected PC/AT C8042 command, status,
  output-buffer, keyboard-enable, and output-port state.
- Changed product behavior: adds an original TypeScript controller core only.

## Basis

- PCjs establishes command-byte flags, status flags, selected command values,
  one controller-visible output buffer, raw keyboard delivery gating, and the
  output-port reset/A20 relation.

## Product Decision

- The core models a bounded one-byte output buffer and returns explicit IRQ1,
  output-port, and reset-pulse results. It does not adopt PCjs's BIOS-oriented
  delayed-output workaround or any runtime dependency.

## Boundary

- Port mapping, PIC routing, physical-memory A20, CPU reset, browser input,
  firmware, storage, display, DOS, and PC110 behavior remain outside P2.
