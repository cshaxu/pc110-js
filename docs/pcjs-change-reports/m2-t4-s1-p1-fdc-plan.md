# M2 T4 S1 P1 PCjs Change Report: FDC Plan

PCjs identifies `0x3F2` as the PC/AT FDC digital-output register and maps the
controller to DMA channel 2 and IRQ6. This planning part records an original
TypeScript controller/media/DMA/IRQ design. It changes no runtime behavior,
imports no PCjs code, and adds no firmware, DOS, filesystem, or disk shortcut.
