# M2 T5 S1 P1 PCjs Change Report: VGA Plan

PCjs defines `0x3B8` as retained MDA mode state and the selected DeskPro 386
machine as IBM VGA. This planning part records an original TypeScript approach
for compatibility ports, VGA registers, video memory, and later presentation.
It changes no runtime behavior and imports no PCjs, BIOS, font, media, or
browser implementation.
