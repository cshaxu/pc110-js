# M1 T1 S3: Record Generic CPU Ceiling

## Objective

Record the highest generic CPU model supported by the selected PCjs v2
reference and preserve the boundary between M2 generic 80386 work and M3
PC110-specific CPU work.

## Non-Goals

- Do not implement any CPU behavior.
- Do not claim complete 80486, 486SX, or 486SL conformance.
- Do not change the existing baseline unless source evidence contradicts it.

## Dependencies

- M1 T1 S1 PCx86 v2 verification.
- Read-only pinned PCjs source object.

## Verification

```powershell
rg -n -C 2 'MODEL_80286|MODEL_80386|MODEL_80486' ../pcjs/machines/pcx86/modules/v2/x86.js
rg -n -C 2 'case X86.MODEL_80386|this.model >= X86.MODEL_80386' ../pcjs/machines/pcx86/modules/v2/cpux86.js
```

## Completion Evidence

The PCx86 v2 model enumeration and CPU implementation show 80386 support and
no 80486 model. Project records continue to reserve PC110 486SX/SL behavior for
M3 as explicit evidence-backed variants or deltas.

## Stop Conditions

Stop and request owner direction if PCjs v2 exposes a later generic CPU model,
if the source evidence conflicts with existing project records, or if resolving
the question requires a broader CPU implementation.
