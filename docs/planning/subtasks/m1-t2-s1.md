# M1 T2 S1: Select Minimal Complete 80386 Machine

## Objective

Select one existing PCjs 80386 PC-compatible machine configuration that can
serve as the M1 browser reference and the M2 hardware contract source.

## Non-Goals

- Do not implement a replacement configuration in PCjs or pc110-js.
- Do not select an 80286-only IBM PC AT configuration as the final 80386
  baseline without an explicit evidence-backed reason.
- Do not begin device implementation or source assimilation.

## Candidate Criteria

- Uses PCx86 v2 and an explicit 80386 CPU model.
- Includes a complete CPU, RAM, ROM, video, FDC, keyboard, chipset, and boot
  path configuration.
- Supports a 1.44MB floppy or has a documented, minimal path to the known-good
  1.44MB local DOS floppy without a guest shortcut.
- Has a browser-served machine XML and dependency closure that can be resolved
  from the pinned Git object.
- Does not require unrelated archive content for the M1 boot proof.
- Keeps M2 scope as close as possible to generic PC/AT hardware behavior.

## Initial Candidates

- `machines/pcx86/compaq/deskpro386/vga/4096kb/machine.xml`.
- `machines/pcx86/compaq/deskpro386/vga/2048kb/machine.xml`.
- IBM 5170 VGA configurations are comparison candidates only because their
  existing XML declares an 80286 CPU.


## Completion Evidence

The selected XML explicitly declares 80386, provides a complete browser
machine, supports the known-good floppy geometry, and has a documented reason
for any machine-specific behavior included in the M2 contract.

## Stop Conditions

Stop and request owner direction if no existing PCjs 80386 candidate supports
the local floppy, if selection would materially replace generic PC/AT scope with
an unsupported machine-specific platform, or if running a candidate requires
protected archive assets beyond locally owned inputs.
