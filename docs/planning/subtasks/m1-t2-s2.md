# M1 T2 S2: Inventory Configured Hardware And Modules

## Objective

Produce a complete, source-pinned inventory of every hardware component and
required PCx86 v2 module used by the selected reference machine.

## Non-Goals

- Do not implement project-native hardware.
- Do not remove a selected machine device merely to reduce the inventory.
- Do not treat a shared PCjs module as a reason to copy it into this repository.

## Dependencies

- Selected source XML:
  `machines/pcx86/compaq/deskpro386/vga/4096kb/machine.xml`.
- Pinned PCjs source commit.
- PCx86 v2 implementation module order documented by PCjs.

## Expected Records

- A device inventory names every direct machine XML component and its referenced
  configuration resource.
- A module inventory distinguishes PCx86 v2 runtime modules, shared v2 modules,
  browser XSL resources, and optional debugger modules.
- Machine-specific DeskPro dependencies are explicitly separated from standard
  PC/AT dependencies.

## Completion Evidence

The inventory contains every selected machine component, direct configuration
dependency, required PCx86 runtime module, and explicit DeskPro-specific item.

## Stop Conditions

Stop and request owner direction if a selected dependency lacks a usable source
or license, if the configuration has an unresolvable dependency outside the
pinned object, or if required module closure cannot be established without
guessing.
