# M1 T2 S4: Reject Unrelated Archive Dependencies

## Objective

Verify that the selected M1 configuration can boot through the validated local
floppy without requiring unrelated PCjs website, archive, or private-disk
content.

## Evaluation

- The selected DeskPro XML references PCjs machine, ROM, video, FDC, HDC,
  keyboard, XSL, and browser-runtime resources required to render the machine.
- Its default FDC `autoMount` names COMPAQ MS-DOS archive disks, and its FDC
  library lists public and private catalog paths.
- Those archive names and catalog paths are not hardware dependencies. The M1
  runner will provide a project-owned startup configuration that replaces the
  default auto-mount state with the validated local floppy.
- No PCjs website page, Jekyll rendering step, archive program, or private disk
  is required after the runner serves the machine XML and its resource closure.

## Rejection Rule

Reject any candidate that cannot reach the local-floppy boot path after default
archive media is removed, or that requires non-pinned web content to resolve
machine hardware resources.

## Completion Evidence

The selected machine remains eligible because its archive-media defaults are
replaceable configuration, while all required hardware and browser resources
are present in the pinned PCjs object.

## Stop Conditions

Stop and request owner direction if overriding default archive media changes
hardware behavior, if local-floppy boot requires a private catalog resource, or
if a missing dependency is outside the pinned object.
