# M1 T2 S5: Record Exact Reference Machine Contract

## Objective

Record the exact selected reference-machine contract that M2 must implement and
test, including standard and DeskPro-specific boundaries.

## Non-Goals

- Do not implement any M2 device.
- Do not add a PC110 profile.
- Do not treat archive media as part of the contract.

## Required Contract Content

- Pinned source identity and source machine XML.
- CPU, bus, RAM, ROM map, video, FDC, HDC, keyboard, serial, mouse, and chipset
  selections.
- Local-floppy boot policy and default archive-media exclusion.
- Browser presentation dependencies.
- Explicit standard PC/AT versus DeskPro-specific implementation boundaries.

## Verification

The contract must agree with the selected XML, the dependency inventory, and
the archive-dependency decision records.

## Stop Conditions

Stop and request owner direction if the contract is ambiguous, omits a selected
device, silently classifies DeskPro behavior as generic, or requires a PC110
hardware decision.
