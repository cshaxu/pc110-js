# M1 T3 S1: Project-Owned Reference Runner

## Objective

Provide a TypeScript command that verifies local inputs, serves the pinned PCjs
reference tree without copying it, and opens the selected M1 machine in a
browser.

## Acceptance

- The command rejects missing sibling source, missing pinned object, wrong
  floppy size, and wrong floppy hash before serving.
- Browser requests resolve PCjs resources from the pinned Git object, not the
  sibling checkout's active branch.
- The generated machine configuration replaces only the archived Compaq DOS
  auto-mount with the verified local floppy.
- The local floppy endpoint is read-only from the host perspective.
- A local browser can load the machine XML, its XSL resources, firmware, and
  floppy through one origin.

## Boundaries

This runner is M1 reference integration only. It must not copy PCjs source,
become the standalone M2 runtime, or modify the sibling checkout.
