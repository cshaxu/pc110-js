# M2 T1 S1: Pinned Toolchain

## Objective

Pin a TypeScript-first standalone toolchain for browser development, headless
tests, linting, formatting, and deterministic project commands.

## Acceptance

- Node.js and pnpm compatibility are declared.
- TypeScript, Vite, Vitest, ESLint, and Prettier versions are exact.
- Build, test, lint, and format commands run from the project root.
- Lockfile records the resolved dependency graph.
- pnpm `allowBuilds` approval is limited to Vite and Vitest's `esbuild`
  runtime dependency.

## Boundary

M1 reference serving remains available but is not the M2 standalone runtime.
