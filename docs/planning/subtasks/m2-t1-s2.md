# M2 T1 S2: Shared Browser And Headless Entries

## Objective

Create browser and Node entry points that instantiate the same project-native
machine core before CPU and device implementation begins.

## Acceptance

- Vite builds and serves a browser entry.
- The Node headless command emits a machine-core snapshot.
- Browser controls and headless startup use `MachineRuntime` directly.
- A focused test verifies the core lifecycle contract.

## Boundary

The lifecycle core is intentionally hardware-neutral. It does not claim to be
an implemented CPU or bootable machine before M2 T2 through T6.
