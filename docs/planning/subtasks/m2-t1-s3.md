# M2 T1 S3: Profiles And Device Contracts

## Objective

Define project-native contracts that let generic PC/AT and future PC110
implementations coexist without profile-specific logic in shared devices.

## Acceptance

- Device kinds, factories, selections, and machine profiles are typed.
- The registry rejects duplicate and unknown variants.
- The contract is covered by a focused test.
- The architecture record preserves generic and PC110 variant boundaries.
