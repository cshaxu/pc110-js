# M2 T2 S1: 80386 CPU State And Reset

## Objective

Implement the PCjs-selected generic 80386 architectural reset state in a
project-native TypeScript state model.

## Non-Goals

- Instruction decode or execution.
- Segment loads, paging translation, exceptions, or interrupts.
- Any 80486 or PC110 CPU behavior.

## Dependencies

- PCjs PCx86 v2 baseline `c7f21b4fa2bdedac3d5c73094a6402fdc8b24c70`.
- M1 80386 CPU ceiling and CPU source map.

## Verification

- `pnpm run build`
- `pnpm run lint`
- `pnpm run test`
- CPU reset-state focused test.

## Stop Conditions

Stop for owner direction if a PCjs reset behavior conflicts with the selected
80386 machine contract or requires an 80486-specific assumption.
