# M2 T2 S2: 80386 Modes And Paging

## Objective

Implement full PCjs-selected 80386 real, protected, virtual-8086, segmentation,
and paging behavior through project-native TypeScript modules.

## Current Part

P1 establishes mode selection, basic cached-segment translation, and a two-level
page-table walker behind a narrow memory interface. P2 adds descriptor-table
decoding, P3 adds descriptor access checks, and P4 adds A/D update plus page
fault metadata. P5 adds a CR3-flushed translation cache and CR2 fault capture.
P6 adds cached segment loading, P7 adds GDT/LDT selection from the selector TI
bit, and P8 validates GDT-resident LDT system descriptors. CPU fault delivery
P9 adds the dedicated protected-mode stack-segment privilege predicate, and P10
adds project-owned GDTR/IDTR state. P11 adds raw 32-bit CR0 state writes; CPU
fault delivery and instruction-driven mode transitions remain for later CPU
work. P12 adds normalized EFLAGS state writes for virtual-8086 mode selection.
P13 adds multi-byte segment-range validation.

## Dependencies And Source

- Pinned PCjs v2 `cpux86.js` and `segx86.js`.
- M2 T2 S1 CPU state.
- Later physical-memory and interrupt modules supply the remaining contracts.

## Verification

- `pnpm run build`
- `pnpm run lint`
- `pnpm run test`

## Stop Conditions

Stop for owner direction only if source evidence requires a PC110/80486-specific
behavior or conflicts with the M1 generic 80386 reference.
