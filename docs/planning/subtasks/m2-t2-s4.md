# M2 T2 S4: Physical Memory, A20, And ROM Mapping

## Objective

Implement the generic PC/AT physical-memory contract: low RAM, immutable ROM
regions and aliases, A20 address gating, and the narrow access surface needed
by CPU execution and later devices.

## Authorized Delivery Order

This subtask begins before M2 T2 S3 is complete under the 2026-07-29 owner
authorization recorded in `docs/planning/breakdown.md`. It is a bounded
dependency correction, not a change to M2 scope or completion criteria.

1. Move existing project-native TypeScript modules into the CPU, memory,
   devices, machine, and firmware boundaries without changing behavior.
2. Add minimal physical memory, A20, and ROM mapping using synthetic test
   fixtures only.
3. Re-run the existing reset-ROM execution trace through the new layout.
4. Resume M2 T2 S3 CPU work only after that trace passes.

## Module Boundaries

- `src/cpu/`: CPU state, decoding, instructions, segments, and control.
- `src/memory/`: physical memory, address translation, paging, and ROM mapping.
- `src/devices/`: device implementations and device-facing contracts.
- `src/machine/`: machine composition and configuration.
- `src/firmware/`: firmware image loading and validation.
- `src/app/`: browser presentation only; it does not own emulation behavior.

## Non-Goals

- Translating or importing nxvm C source.
- Rewriting working CPU behavior during the structural move.
- Guest-service, DOS, BIOS, or PC110 shortcuts.
- Implementing device models, I/O dispatch, shadow RAM, or broad memory forms
  beyond the capability necessary to resume the existing trace.

## Dependencies And Sources

- M2 T2 S1 reset-state contract and M2 T2 S2 translation contract.
- M2 T2 S3 P16 reset-ROM trace.
- Pinned PCjs v2 `c7f21b4fa2bdedac3d5c73094a6402fdc8b24c70` for behavior
  evidence and architecture comparison only.
- NXVM `src/device/vcpu.h` and `src/device/vcpuins.c` as a structural,
  data-model, and trace-design reference only; no NXVM source translation is
  authorized. Deprecated NXVM CPU code is excluded.
