# M2 T2 S5: I/O, Reset, Deterministic Stepping, And Trace

## Objective

Close the generic project-native machine boundary between the rebuilt CPU and
I/O ports, reset, deterministic instruction stepping, and trace hooks. This
subtask supplies contracts and generic dispatch only; native PC/AT device
models remain M2 T3 work, and temporary PCjs device proxies remain S6-only.

## Entry Conditions

- S3 executable NXVM CPU coverage is closed within its explicit TODO boundary.
- S4 physical memory, A20, ROM aliases, and the selected M1 RAM map are closed.
- The selected-ROM trace identifies unavailable project-native I/O as the next
  whole-machine boundary.

## Delivery Order

1. Audit existing rebuilt port-bus, reset, runner, and trace contracts against
   the selected-ROM boundary.
2. Define deterministic port-read/write dispatch with explicit unmapped-port
   behavior and no synthetic BIOS or device response.
3. Connect reset and bounded stepping to the rebuilt CPU through project-native
   machine composition without reactivating the legacy CPU.
4. Add trace hooks that expose instruction, port, reset, and stop boundaries.
5. Re-run the selected-ROM trace until the next missing device behavior is
   classified without implementing that device.

## Non-Goals

- M2 T3 PIC, PIT, DMA, RTC, keyboard-controller, storage, video, or chipset
  implementation.
- BIOS, DOS, guest-service, filesystem, PC110, or synthetic port hacks.
- PCjs device execution, except the separately authorized S6 verification
  harness after S5 closes.

## Acceptance

- The rebuilt CPU uses a project-native port dispatch contract and has explicit
  behavior for unclaimed ports.
- Reset, bounded stepping, and trace output are deterministic and do not use
  the legacy CPU at runtime.
- The selected-ROM trace reaches and records the next genuine device boundary
  without invented port values.
- Focused tests, full gate, tracking, provenance, and verification records pass.
