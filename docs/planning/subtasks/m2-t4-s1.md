# M2 T4 S1: Selected Floppy Controller And Drive Behavior

## Objective

Implement a project-native PC/AT floppy-controller and drive model sufficient
for the selected DeskPro 386 firmware to reset, identify, seek, and read a
boot sector through real controller, IRQ6, DMA channel 2, and raw-media paths.

## Scope And Sources

- Behavioral authority: pinned read-only PCjs `fdc.js`, selected machine
  configuration, and `chipset.js` DMA channel 2 / IRQ6 ownership.
- Product code: original TypeScript in `src/devices/`, `src/machine/`, and
  `src/firmware/`; no PCjs runtime or source import.
- Controller ports: DOR `0x3F2`, main status `0x3F4`, data `0x3F5`, and
  digital-input/control `0x3F7`, all byte-wide.
- Initial command families: SPECIFY, SENSE DRIVE, RECALIBRATE, SENSE
  INTERRUPT, READ ID, SEEK, and READ DATA. Unsupported commands must report
  controller-defined invalid-command state, never a guest-service result.

## Boundaries

- Raw floppy images are sector media, not DOS filesystems. No DOS, BIOS INT 13,
  filesystem, host path lookup, or synthetic boot-sector delivery is allowed.
- The FDC owns command/result phase and drive state. A machine adapter owns
  ports, IRQ6 routing, DMA channel-2 requests, and explicit advancement.
- Drive geometry and write-protect state are configuration inputs. Controller
  behavior may not infer guest semantics from image contents.
- FDC timing remains deterministic and explicitly advanced; no host clock.

## Execution Order

1. Record register, DOR reset/enable, command/result phase, IRQ6, DMA2, raw
   media, and selected-ROM boundary evidence.
2. Add an isolated 765/8272-compatible controller state model for DOR,
   status, command collection, result FIFO, reset, and selected non-data
   command families; prove invalid-command and interrupt acknowledgement paths.
3. Add a raw sector-image drive model with fixed geometry, attach/eject,
   ready, write-protect, and CHS lookup behavior.
4. Add READ DATA and READ ID through explicit DMA channel-2 endpoint requests,
   result bytes, terminal count, errors, and IRQ6.
5. Compose the selected port group and drive configuration in the machine,
   then advance the selected ROM to the next real boundary without a firmware
   or DOS shortcut.
6. Add write/format behavior only when the selected machine and boot workload
   require it; preserve read-only media as a first-class configuration.

## Verification

- Focused tests cover every owned port, width, DOR enable/reset, main-status
  direction/ready/busy bits, command/result FIFO, invalid command, selected
  seek/recalibrate/sense/read-id behavior, and IRQ acknowledgement.
- Raw-media tests cover geometry, CHS, attachment, write protection, and no
  filesystem interpretation.
- Integration tests cover DMA2 address/count/page progression, endpoint data,
  terminal count, IRQ6, and BIOS-issued boot-sector reads.
- The selected-ROM trace records each advance and first unavailable boundary.
- Full gate: `pnpm run format`, `pnpm run build`, `pnpm run lint`,
  `pnpm run test`, and `git diff --check`.

## Stop Conditions

Stop for owner direction only if the selected FDC behavior needs a protected
asset, a source conflict, or a machine-specific wiring claim unsupported by
the pinned reference and focused evidence.

## P2 Controller Core

P2 implements an isolated controller state model. It covers DOR reset/enable,
main-status phase direction, control/data state, command collection, result
FIFO, reset-completion SENSE INTERRUPT sequencing, SPECIFY, SENSE DRIVE,
SEEK, RECALIBRATE, and invalid-command results. It records drive-ready and
cylinder state but owns neither media nor ports, PIC, DMA, or host time.

READ ID and READ DATA are recognized but return a controller invalid-command
result until later parts supply real raw-media and DMA execution. No sector
bytes, BIOS response, or synthetic boot completion is produced by P2.

## P3 Raw Sector Media

P3 adds a geometry-validated raw CHS drive with attach, eject, ready,
write-protect, change-line state, and defensive sector reads. It defines the
selected 1.44MB geometry but does not load the protected local image, parse a
filesystem, attach the drive to the FDC, or move data through DMA.
