# M2 T5 S5: Additional Selected Devices

## Objective

Implement every selected M1 device not owned by earlier T3-T5 subtasks as
project-native TypeScript hardware. Start with COM1 because the selected
DeskPro ROM reads its IIR at `0x3FA`.

## COM1 16550 Scope

- Behavioral authority: pinned read-only PCjs `serial.js` and the selected
  DeskPro 386 machine configuration.
- Ports: complete `0x3F8`-`0x3FF` register family, including DLAB aliases.
- State: divisor, IER, IIR, FCR, LCR, MCR, LSR, MSR, scratch, RX/TX FIFO, and
  modem-status deltas.
- Events: receive-data, transmit-holding, line-status, modem-status, FIFO
  threshold, IIR priority, and native IRQ4 admission.
- Host boundary: byte ingress and transmitted-byte observation are device-core
  contracts; browser serial APIs are not part of the UART.

## Boundaries

- No PCjs runtime, source import, BIOS service, DOS shortcut, or host serial
  transport is permitted.
- Do not implement only `0x3FA`; the IIR read must arise from the complete UART
  state machine.
- COM2, mouse transport, browser UI, and networking remain separate selected
  device work unless ROM evidence reaches them.

## Verification

- Focused tests cover all port aliases, DLAB, FIFO, interrupt priority and
  clearing, line/modem state, reset, byte width, IRQ4, and machine composition.
- The selected ROM trace must cross `0x3FA` through native UART state.
- Full gate: `pnpm run format`, `pnpm run build`, `pnpm run lint`,
  `pnpm run test`, and `git diff --check`.
