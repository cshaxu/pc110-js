# M2 T3 S6 8042 Provenance

## Reference Boundary

- Behavioral reference: pinned read-only PCjs
  `machines/pcx86/modules/v2/chipset.js`, C8042 port, status, command-byte,
  output-port, command, and IRQ definitions.
- Product code: original TypeScript only. No PCjs runtime, device source,
  firmware, media, browser event, host service, or guest-service behavior is
  imported.

## Selected Contract

The selected PC/AT controller owns 8-bit ports `0x60` and `0x64`. Data reads
consume the controller output buffer; status reads expose controller state;
command writes select controller operations; data writes supply command data or
keyboard-directed data. The command byte gates controller-originated IRQ1.
The controller output port routes A20 and reset only through the existing S5
contract.

## P1 Plan Boundary

P1 establishes a controller core, PC/AT adapter, raw scan-byte ingress, and
native PIC IRQ1 path. `0x61` remains owned by the S5 system-control adapter.
The implementation will use deterministic local response boundaries rather
than a BIOS polling delay. Browser keyboard mapping, scan-code source policy,
secondary controllers, firmware, storage, display, DOS, and PC110 behavior
remain excluded.

## P2 Controller State Core

The isolated TypeScript core represents the selected command byte, input and
output ports, one-byte output buffer, pending data command, and status bits.
It records output-port and reset-pulse effects as explicit results for later
machine composition. It does not import PCjs, map ports, call the PIC, change
physical memory, reset a CPU, or accept browser input.
