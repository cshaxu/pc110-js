# M2 T5 S6 P146 Architecture Authority

## Owner Direction

The owner confirmed the intended product synthesis: NXVM-style native project
structure and readable CPU boundaries without NXVM platform hacks; PCjs-style
whole-machine behavior and flexible profiles without PCjs JavaScript; and
future PC110 profiles informed by PC110-EMU ROM and hardware evidence without
its hardcoded boot workarounds.

## Effect

This part consolidates existing scattered rules into one architecture-authority
policy. It does not change emulation behavior, CPU coverage, device behavior,
media ownership, milestone numbering, or profile selection.
