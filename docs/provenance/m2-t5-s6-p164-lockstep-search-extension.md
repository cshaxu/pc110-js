# M2 T5 S6 P164 Lockstep Search Extension Provenance

## Trigger

P163 eliminated the PIT0 difference at `F000:B5B7` and the cold search then
matched 131,072 boundaries. A subsequent bounded native browser workload still
reached the established `F000:C24B` keyboard-buffer wait, while M1 records the
same PCjs machine reaching `A:\\>` with identical local floppy media.

## Project-Native Work

Only the diagnostic caller limit changes from 131,072 to 262,144 instructions.
The coordinator, 1,024-instruction batch size, compared fields, reset path,
and final-batch single-step replay are unchanged.

## Non-Transfer

No PCjs source or product runtime behavior changes. This is not a device
proxy, state transfer, compatibility exception, or firmware workaround.
