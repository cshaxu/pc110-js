# M1 License And Archive Boundary

## PCjs Software

PCjs PCx86 v2 is the M1 and M2 standard-PC reference under its MIT license.
The canonical license copy is `third_party/licenses/PCjs-LICENSE.txt`; notices
are recorded in `THIRD_PARTY_NOTICES.md`.

M2 may study, derive from, or adapt PCjs behavior only with exact provenance
and preserved MIT attribution. It must use project-native TypeScript structure,
not a permanent copied JavaScript runtime tree.

## Excluded Material

The PCjs license excludes third-party archival programs, images, and
documentation from its software grant. M1 therefore excludes:

- COMPAQ DOS archive auto-mount definitions and disk catalogs;
- PCjs ROM JSON and IBM VGA ROM JSON from redistribution;
- the local `fdd.img` and all PC110 ROM or disk material;
- PC110-EMU source until its licensing and permission are separately resolved.

M1 serves protected inputs only from local sibling or parent paths; none are
tracked by this project.
