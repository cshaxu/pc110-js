## S2: Implement Modes And Paging

- P1: Added mode selection, cached-segment translation, and a two-level paging
  walker; full 80386 descriptor, fault, and TLB behavior remains active.
- P2: Added bounded GDT/LDT descriptor decoding; segment loading and privilege
  behavior remain active.
- P3: Added segment permission, privilege, and expand-down predicates; fault
  state and segment-cache integration remain active.
- P4: Added PDE/PTE accessed and dirty updates with structured page-fault
  metadata; CPU exception delivery and TLB behavior remain active.
- P5: Added CR3-flushed translation caching and CR2 page-fault capture; CPU
  exception delivery remains active.
- P6: Added mode-aware cached segment loading through validated GDT descriptors;
  LDT, gates, tasks, and exception delivery remain later CPU work.
- P7: Added selector TI-bit routing between the GDT and an explicitly supplied
  LDT; descriptor-table loading, gates, tasks, and exception delivery remain.
- P8: Added validation and extraction of present LDT system descriptors from the
  GDT; LDTR instruction state, gates, tasks, and exception delivery remain.
- P9: Added the dedicated protected-mode stack-segment type and privilege
  predicate; opcode dispatch, gates, tasks, and exception delivery remain.
- P10: Added independent GDTR and IDTR state with 80386-width base and limit
  normalization; descriptor-table instructions and interrupt delivery remain.
- P11: Added a raw 32-bit CR0 state-write boundary; privileged instruction
  checks, mode-transition side effects, and TLB coordination remain later work.
- P12: Added normalized EFLAGS state writes for virtual-8086 mode selection;
  `POPF` and `IRET` privilege semantics remain later instruction work.
- P13: Added multi-byte normal and expand-down segment-range validation;
  instruction memory accesses remain part of later CPU execution work.
- Completion: The mode, segmentation, descriptor-table, and paging contract
  passed [verification](../verification/m2-t2-s2-modes-paging.md). Instruction
  execution, exception delivery, gates, and tasks move to S3.

## S3: Implement Opcode Families And Privilege Behavior

- P1: Established the execution record, source boundary, delivery order, and
  verification requirements; implementation is active.
- P2: Added a project-native CS:EIP single-byte opcode-fetch contract with a
  focused reset-vector test; decode and execution remain active.
- P3: Added NOP and HLT execution, EIP commit, halted state, and unsupported
  opcode preservation; general decoding and exception delivery remain active.
- P4: Added real-mode `JMP FAR ptr16:16` for reset-vector control transfers;
  protected-mode far jumps remain active privilege work.
- P5: Added real-mode `MOV r16, imm16`, `JMP rel8`, and `JMP rel16` execution
  with 16-bit IP wrapping; operand-size prefixes remain active decode work.
- P6: Added `MOV r8, imm8` and `OUT imm8, AL` with a port-writer boundary for
  the observed reset-ROM path; actual port dispatch remains T2 S5 work.
- P7: Added SAHF and real-mode CLI flag transitions from the observed ROM path;
  protected-mode CLI remains active privilege work.
- P8: Added the observed `0F 01 F0` register-form LMSW behavior with PE and
  fixed-bit preservation; general ModR/M and memory forms remain active work.
