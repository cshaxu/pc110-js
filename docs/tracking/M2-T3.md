# M2 T3: TypeScript Core PC/AT Hardware

## S1: 8259A-Compatible PIC Variants

- P1: Recorded the project-native master/slave 8259A execution plan, selected
  PC/AT ports, cascade boundary, sources, verification, and non-goals.
- P2: Added the project-native single-8259A ICW/OCW, fixed-priority, mask,
  IRR/ISR, EOI, and vector-acknowledgement state core.
- P3: Composed native master/slave PICs with IRQ2 cascade arbitration, vector
  acknowledgement, and four explicit 8-bit PC/AT port-bus ranges. CPU INTR
  admission remains P4.
- P4: Registered the native PIC in the rebuilt machine core and delivered
  pending vectors only at CPU-accepted boundaries, including HLT and STI
  inhibition behavior.
- P5: Added and manually checked a browser-native CPU/PIC reset-state
  checkpoint. S1 is complete; no firmware or DOS workload is claimed.

## S2: 8253/8254-Compatible PIT And Speaker Timing

- P1: Recorded the native PIT plan, PC/AT port and wiring evidence, strict
  T3 S5 speaker-gate boundary, verification matrix, provenance, and stops.
- P2: Added a standalone binary 8254 counter model with control, latching,
  modes 0-5, gate transitions, read-back, and explicit tick output edges.
- P3: Mapped native PIT ports, explicit PIT advancement, counter-0 IRQ0 into
  the native PIC/CPU path, and counter-2 output observation without a host clock.
- P4: Added and manually verified browser-visible native PIT reset outputs.
  S2 is complete; no running clock, speaker gate, sound, firmware, or DOS claim.

## S3: 8237-Compatible DMA And Page Registers

- P1: Recorded the native DMA controller/page-register plan, cascade and port
  evidence, FDC boundary, verification matrix, provenance, and stop conditions.
- P2: Added standalone 8237 register, grant, terminal-count, priority,
  mask/request, auto-init, decrement, and byte/word addressing state behavior.
- P3: Registered native DMA0/DMA1 and selected page-register ports in the
  rebuilt machine, including DMA1 even-port and reset behavior.
- P4: Added DMA1 channel-4 cascade arbitration and generic grant-driven memory/
  endpoint transfer behavior without an FDC or storage implementation.
- P5: Added and manually verified browser-native DMA reset masks. S3 is
  complete; no requesting device, FDC, storage, firmware, or DOS claim.

## S4: RTC/CMOS And Selected-Machine Configuration

- P1: Recorded the project-native MC146818-compatible RTC/CMOS plan, selected
  PC/AT `0x70`/`0x71` and IRQ8 evidence, deterministic-time boundary, and the
  deferred S5 NMI boundary. No runtime behavior changed.
- P2: Added an isolated deterministic RTC/CMOS state model with calendar,
  BCD/binary and 12/24-hour forms, SET, periodic/update/alarm status,
  status-C acknowledgement, and checksum behavior. Ports, IRQ8, NMI, host
  time, firmware, storage, and browser behavior remain outside this part.
