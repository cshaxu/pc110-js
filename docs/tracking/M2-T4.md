# M2 T4: TypeScript Storage Hardware

## S1: Selected Floppy Controller And Drive Behavior

- P1: Recorded the source-established PC/AT FDC plan after the selected ROM
  reached DOR `0x3F2`. The planned controller owns real ports, command/result
  state, DMA2, IRQ6, raw sector media, and boot-sector reads; BIOS, DOS, and
  filesystem shortcuts remain prohibited.
- P2: Added an isolated native 765/8272 command/result state core with DOR,
  main-status, reset SENSE queue, selected non-data commands, drive state,
  and explicit invalid-command results. Media, DMA2, IRQ6, ports, and
  boot-sector behavior remain unimplemented.
- P3: Added a geometry-validated raw CHS drive with attachment, ejection,
  change-line, write-protect, and sector access contracts. The selected 1.44MB
  geometry is defined without loading or tracking protected media; no FDC or
  DMA connection exists yet.
- P4: Connected raw READ ID/READ DATA execution to native FDC ports, IRQ6,
  explicit DMA2 grants, and physical memory. The guest must configure DMA;
  protected media is not auto-mounted, and no BIOS/DOS/filesystem shortcut or
  write/format behavior is present. The selected trace reaches `F000:BB30`
  after 221 instructions and stops at display-domain port `0x3B8`.

## S3: Selected Fixed Storage Hardware

- P1: Recorded the selected primary AT controller plan for the IBM Type 5 raw
  fixed-disk geometry (`940x6x17x512`), `0x1F0`-`0x1F7`/`0x3F6` ports, and
  IRQ14. No HDC product behavior is added in this planning part.
- P2: Added a project-native raw Type 5 fixed-drive media contract with exact
  CHS geometry, explicit attachment/ejection, sector bounds, defensive reads,
  and write-protect handling. It adds no controller ports, guest services, or
  protected media.
- P3: Added the native primary AT controller register/device-control family,
  non-data command paths, status/error/reset behavior, drive selection, and
  IRQ14 routing. PIO sector commands remain explicitly unsupported pending a
  real transfer state machine.
- P4: Added real PIO `READ DATA` from attached raw CHS sectors, including
  byte/word data-port reads, DRQ, IRQ14 service points, sector-count and CHS
  progression, and terminal/error state. Media attachment remains explicit;
  write and identify commands are still outside this part.
