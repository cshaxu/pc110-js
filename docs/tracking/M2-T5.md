# M2 T5: TypeScript Video, Input, And Platform Presentation

## S1: Selected VGA Hardware And Video Memory

- P1: Recorded the selected IBM VGA plan after the ROM reached MDA-compatible
  mode port `0x3B8`. Compatibility state, VGA registers, video memory, and
  browser presentation are separated; no diagnostic sink, BIOS/DOS shortcut,
  font, or renderer was added.
- P2: Added the complete retained MDA compatibility CRTC/mode/status port
  family as project-native VGA-visible state. The selected ROM reaches
  `F000:BB36` after 224 instructions and stops at CGA compatibility port
  `0x3D8`; no MDA renderer, printer, or VGA main-register behavior is claimed.
- P3: Added the complete retained CGA compatibility CRTC/mode/color/status
  family as project-native VGA-visible state. The selected ROM reaches
  `F000:BB44` after 231 instructions and stops at VGA attribute-controller
  port `0x3C0`; no CGA renderer, framebuffer, or VGA main-register behavior is
  claimed.
- P4: Added the retained native VGA Attribute Controller, including its
  index/data flip-flop, palette gating, all palette/control register classes,
  and status-one reset. The selected fixed-budget ROM trace completes 1,000
  instructions at `F000:9C05`; no renderer, framebuffer, video-memory plane,
  or successful boot is claimed.
- P5: Added the complete retained VGA sequencer bank and opt-in selected-ROM
  trace budget/tail diagnostics. The extended trace reaches the ROM's
  `F000:BBB4` PIT counter-zero POST failure loop. A proposed per-instruction
  PIT clock was rejected before commit because it produced premature IRQ0;
  later scheduling must use CPU cycles, not instruction counts.
- P6: Added project-native step-cycle accounting and exact fractional PIT
  scheduling, plus the selected early-80386 `MOV CR` MOD-field compatibility
  behavior. The native trace now crosses the real protected-mode far jump to
  `0018:87AA` and returns to `F000:87DC`; full 80386 timing and other device
  clock domains remain explicit `TODO(High)` work.
- P7: Exposed native PIT channel-1 refresh state at PC/AT `0x61` bit 4 without
  altering timer-2/speaker ownership. The selected trace advances beyond the
  ROM refresh loop to `F000:B5F7`; audio and complete scheduler behavior remain
  outside this part.
- P8: Added the physical-memory hardware-aperture contract required by native
  VGA memory. Device windows observe A20-normalized addresses, overlay writable
  RAM only, and cannot overlap immutable ROM or another device. No VGA plane,
  renderer, or browser presentation is claimed.
- P9: Added and composed the complete retained VGA Graphics Controller register
  family at `0x3CE`/`0x3CF`, with defined index masks and reset behavior. The
  native plane/latch aperture remains the following part.
- P10: Composed native A0000-BFFFF VGA planar memory with four planes, latches,
  window decoding, addressing modes, and Graphics Controller read/write modes.
  Browser presentation remains separate.
- P11: Transferred shared `0x3D4/0x3D5` ownership to native VGA CRTC state while
  retaining CGA mode/color/status compatibility ports. CRTC display-start and
  cursor values are available to later presentation.
- P12: Added native Miscellaneous Output and 256-entry DAC state, including
  6-bit RGB palette transfers and address advancement, for later presentation.
- P13: Added a browser canvas fed by a native text framebuffer projection of
  VGA planes, CRTC display start, and DAC palette state. It is not DOS boot or
  complete VGA rendering evidence.
- Browser runtime audit: native FDC/DMA exists, but no browser-owned, validated
  DeskPro ROM or floppy asset contract exists yet. The M1 PCjs reference media
  path is explicitly excluded from the M2 runtime.
- P14: Added selected local-media descriptors, SHA-256 validation, native ROM
  alias mapping, native FDC floppy attachment, and browser-run-loop gating.
  User-provided files remain required; neither PCjs nor host paths are runtime
  asset sources.
- P15 evidence: validated local floppy attached to native FDC does not advance
  the ROM beyond its PIT polling loop at `F000:C668`; timer behavior remains
  the next whole-machine blocker.
- P16: Replaced selected generic CPU timing fallbacks with explicit
  compatibility classes for stack, return, exchange, and short-jump paths. The
  one-million-instruction native trace improved PIT0 count from 27596 to 9644,
  but did not demonstrate an FDC command or boot.
- P17: Bound native ROM diagnostic event retention to the requested tail and
  optional CS-transfer events so multi-million-instruction traces remain a
  fixed-memory execution diagnostic; no machine behavior changes.

## S5: Additional Selected Devices

- P1: Planned complete native COM1 16550 behavior after the selected DeskPro
  ROM reached IIR port `0x3FA`. No UART port behavior is added in this part.
- P2: Added a project-native COM1 16550 register model with DLAB aliases,
  FIFO state, interrupt priority, line/modem status, loopback, transmit
  observation, and native IRQ4 composition. The selected ROM crosses `0x3FA`
  and next stops at COM2 IIR `0x2FA`; COM2 remains the next same-family part.
- P3: Composed the same native UART model as COM2 at `0x2F8`-`0x2FF` with
  IRQ3. This is separate machine wiring, not a duplicated serial device; the
  selected ROM trace is the follow-up acceptance evidence.
- P4: Added selected-machine floating/ignored behavior for unpopulated I/O,
  preserving strict port-bus defaults for focused tests. This matches the
  BIOS probe of absent `0x3BC`; the configured LPT at `0x378` remains a
  separate native-device requirement.
- P5: Added the configured native LPT1 register family at `0x378`-`0x37A`,
  including reset state, status/control semantics, ACK-driven IRQ7, and a
  host-independent transmit observation boundary.
