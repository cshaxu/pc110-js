# M2 T3 S6 P1 Verification: 8042 Plan

The plan records selected PC/AT `0x60`/`0x64`, controller command/status,
output-buffer, command-byte IRQ1, output-port, and raw keyboard-byte ingress
ownership. It preserves S5 ownership of `0x61` and excludes browser input,
firmware, storage, display, DOS, PC110, and synthetic guest behavior. No
runtime behavior is introduced by this part.
